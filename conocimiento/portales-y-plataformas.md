# Portales y plataformas UVG

Fuente: sección "Portales y plataformas" de https://www.uvg.edu.gt/. Los enlaces se listaron desde la página principal. La página no describe la función de cada plataforma, así que el asistente debe presentarlas por su nombre y no inventar lo que hacen. Si el usuario tiene una falla, debe remitir a la mesa de ayuda.

## Estudiantes

- **Portal electrónico:** https://portal.uvg.edu.gt/. Es el portal académico. La preinscripción y la asignación de clases a partir del segundo ciclo se hacen aquí.
- **Canvas:** https://uvg.instructure.com
- **Correo UVG:** https://outlook.office.com/mail/
- **Evolution:** https://dante.uvg.edu.gt/Evolution/Account/Login?ReturnUrl=%2fevolution
- **UVG+:** http://plus.uvg.edu.gt/
- **Mesa de ayuda (ServiceNow):** https://uvgservicenow.atlassian.net/servicedesk/customer/portals
- **Reglamentos para estudiantes:** https://www.uvg.edu.gt/nosotros/reglamentos-estudiantes/
- **Validación de títulos:** https://www.uvg.edu.gt/validacion-titulos/
- **Admisiones (solicitud):** https://admisiones.uvg.edu.gt/

## Colaboradores

- **Intranet:** https://intranet.uvg.edu.gt/#/page/login
- **Reglamentos para colaboradores:** https://www.uvg.edu.gt/nosotros/reglamentos_colaboradores/

## Mesa de ayuda

Para problemas con las plataformas, la vía oficial es la mesa de ayuda en ServiceNow (enlace arriba). Si el asistente no puede resolver el caso, debe indicar ese enlace y el contacto de la central.
